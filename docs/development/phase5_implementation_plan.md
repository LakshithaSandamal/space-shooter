# Phase 5 — Sectors, Threat, and Hazard Expansion

## Goal

Expand the survival loop into a sector-based threat system while preserving the three-lane fairness model.

## Implementation order

1. Sector runtime state
2. Threat level controller
3. Sector-specific visual/audio hooks
4. Hazard framework expansion
5. Authored hazard patterns
6. Fairness validation
7. Gameplay review scene

## New sectors

- Courier Corridor
- Wreck Belt
- Ion Reach
- Solar Rift
- Void Passage

## Threat progression

Threat levels 1-5 modify:

- spawn pressure
- hazard combinations
- timing windows
- visual intensity

## Hazards

- Heavy Asteroid
- Fast Debris
- Drifting Debris
- Energy Mine
- Laser Gate
- Meteor Strike
- Cargo Wreck
- Gravity Anomaly

## Rules

- No phase 6 route/contract systems.
- No impossible three-lane patterns.
- Hazards must use deterministic validation.
- Existing Courier, combo, and power-up systems remain compatible.
